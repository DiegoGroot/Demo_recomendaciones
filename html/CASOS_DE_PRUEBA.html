Caso de Prueba CP-EST-001

ID: CP-EST-001
Módulo: Estudiantes
Tipo: Funcional

Objetivo

Verificar que se puede registrar un estudiante nuevo con todos los datos válidos correctamente en el sistema.

Requisito Relacionado

REQ-EST-01: El sistema debe permitir el registro de nuevos estudiantes con validación de datos únicos (email).

Precondiciones

  • Base de datos conectada y operativa
  • API backend ejecutándose en http://localhost:8000
  • Al menos una carrera creada en el sistema

Datos de Entrada

Campo Valor
Nombre Juan Carlos Pérez
Email juan.perez@universidad.edu
Contraseña Pwd123!Secure
Carrera Ingeniería en Sistemas

Pasos de Ejecución

  1. Abrir Postman o cliente HTTP
  2. Hacer POST a /api/estudiantes
  3. Incluir datos en formato JSON
  4. Enviar solicitud
  5. Verificar respuesta del servidor
  6. Consultar BD para confirmar registro

Resultado Esperado

  • Código HTTP 201 (Created)
  • Respuesta JSON con ID del estudiante
  • Mensaje de éxito: "Estudiante creado correctamente"
  • Registro visible en base de datos
  • Promedio inicial en 0.00
